01

Comment procéder

  1. Préparez l'environnement (bloc suivant) et vérifiez que le tableau de bord affiche 8 employés.
  2. Suivez les scénarios dans l'ordre : ils s'enchaînent comme le cycle de paie (les données créées par un scénario servent au suivant).
  3. Pour chaque scénario : dépliez-le, exécutez les étapes dans l'application, comparez avec le résultat attendu (les chiffres sont calculés, ils doivent correspondre exactement), puis cochez « Validé ».
  4. Si un résultat diverge : notez le scénario, l'étape et la valeur observée — et relancez l'équivalent CLI pour distinguer un problème d'écran d'un problème de calcul.
  5. Les scénarios marqués attention modifient l'état de façon durable (clôture, rôles) : lisez l'avertissement avant d'agir.
  6. Terminez par les tests automatisés (dernier scénario) : ils garantissent les invariants quel que soit ce que vous avez saisi.
02

Prérequis & données de démo

  1. Deux terminaux dans app/ : npx convex dev (backend) et npm run dev (front, http://localhost:5173).
  2. Variable AUTH_DEV_BYPASS=true sur le déploiement Convex (déjà définie) : vous êtes connecté comme Directeur (dev) · niveau 7.
  3. Sur le tableau de bord, si l'effectif est vide : « Initialiser les données de démo ». Idempotent — relançable sans doublon.
  4. Pour les scénarios marqués CLI, utilisez Git Bash (les guillemets JSON sont abîmés par PowerShell) :
# forme générale — même code que l'interface

04

Invariants garantis (vérifiés par les tests)

Ce que le moteur garantit quel que soit le scénario. npm run test:paie rejoue 12 contrôles ; la logique des absences en a 9.

Net = Brut − Total des retenues

Et le total des retenues est exactement la somme des lignes listées sur le bulletin (cotisations, sanctions, dettes, acompte, charges du registre).

Barème daté

Un bulletin référence la version du barème applicable à sa période. Un mois clôturé n'est jamais recalculé avec un barème plus récent.

CNPS plafonnée

La base des cotisations CNPS/PVID est plafonnée (750 000 FCFA dans le barème indicatif) ; CFC, FNE et IRPP suivent leurs bases propres.

Salaire proratisé

salaire du mois = brut × jours travaillés / 30. Seules les absences non rémunérées entament les jours travaillés.

Clôture = gel

Après « Générer et clôturer », bulletins figés (snapshots), saisie / planning / primes en lecture seule, courrier basé sur les snapshots.

Accès par niveau

Chaque route a un niveau minimum (paie = 4, paramètres = 7). Le rôle auditeur externe ne voit que le tableau de bord et l'audit.
